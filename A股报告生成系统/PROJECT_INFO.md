# A股研究报告批量生成系统 - 项目说明

## 🎯 项目概述

这是一个全自动化的A股研究报告生成系统，可以为所有A股上市公司生成专业的研究报告。

**版本：** v2.0
**最后更新：** 2026-01-19
**项目位置：** `C:\Users\ge0rg\Desktop\A股报告生成系统`

---

## 📦 项目文件清单

### 核心文件（src/）
- `qianwen_client.py` - 千问API客户端，生成报告内容
- `report_generator.py` - Word文档生成器
- `main.py` - 主程序，整合所有模块
- `data_fetcher.py` - 数据获取模块（akshare）

### 配置文件（config/）
- `.env` - 环境变量配置（包含API密钥）

### 数据文件（data/）
- `remaining_stocks.txt` - 待生成的股票代码列表

### 输出文件夹
- `output/` - 生成的Word报告（自动创建）
- `logs/` - 运行日志（自动创建）

### 启动文件
- `start.bat` - Windows一键启动脚本
- `batch_generate.py` - 批量生成主脚本
- `requirements.txt` - Python依赖列表

### 文档
- `README.md` - 详细说明文档
- `QUICKSTART.md` - 快速开始指南

## 📊 报告规格

### 文件格式
- **格式：** Microsoft Word (.docx)
- **文件名：** 公司名称.docx
- **编码：** UTF-8

### 报告结构
```
标题：公司名称（股票代码）研究报告

一、投资建议
   - 投资评级：强烈推荐/推荐/持有/不建议持有
   - 核心逻辑：100-150字

二、投资逻辑 ⭐新增
   - 行业前景分析
   - 公司竞争力评估
   - 成长性分析
   - 估值合理性判断
   - 字数：200-300字

三、公司概况
   - 主营业务和行业地位
   - 字数：100-150字

四、财务数据分析
   - 主要财务指标（近三年）
   - 财务数据分析
   - 字数：200-250字

五、业务展望和行业地位
   - 业务发展前景
   - 行业地位分析
   - 字数：200-250字

六、可比上市公司对比
   - 同行业对比分析
   - 竞争优势
   - 字数：150-200字
```

### 内容特点
- ✅ 数据真实可靠（基于akshare实时数据）
- ✅ 积极但不失客观
- ✅ 无AI痕迹（去AI味处理）
- ✅ 专业简洁（像人类研究员）

## 🎨 亮点功能

### 1. 投资逻辑分析（新增）
深入分析投资该公司的核心逻辑，包含：
- 行业前景
- 公司竞争力
- 成长性
- 估值合理性

### 2. 智能文件命名
自动使用公司名称作为文件名，例如：
- `平安银行.docx`（而不是 000001.docx）
- `万科A.docx`（而不是 000002.docx）

### 3. 断点续传
- 程序中断后可继续生成
- 自动跳过已生成的股票
- 无需手动干预

### 4. 错误处理
- 网络错误自动重试（5次）
- API限流自动等待（60秒）
- 失败后继续下一个

## ⚙️ 配置说明

### API密钥配置

编辑 `config/.env` 文件：
```
DASHSCOPE_API_KEY=sk-your-api-key-here
```

获取API密钥：https://dashscope.aliyun.com/

### 自定义股票列表

编辑 `data/remaining_stocks.txt` 文件：
```
# 每行一个股票代码
000001
000002
000004
...
```

## 💡 使用技巧

### 1. 分批生成
如果不想一次性生成所有报告，可以：
1. 编辑 `data/stocks_code.txt`
2. 只放入需要生成的股票代码
3. 运行 `batch_generate.py`

### 2. 后台运行
使用Windows任务计划程序：
1. 打开"任务计划程序"
2. 创建基本任务
3. 设置触发器（每天特定时间）
4. 操作：启动程序 `batch_generate.py`

### 3. 监控进度
查看日志文件：
```bash
tail -f logs/batch_generation_*.log
```

## 📞 常见问题

**Q1: 为什么有些股票生成失败？**
A: 可能原因：
- 数据暂时不可用
- 网络连接问题
- API限流

解决方案：程序会自动重试，失败的可单独重试

**Q2: 如何查看已生成多少报告？**
A: 检查 `output/` 目录：
```bash
dir output\*.docx | find /c ".docx"
```

**Q3: 可以同时运行多个实例吗？**
A: 不建议，可能导致API限流

**Q4: 程序可以在服务器上运行吗？**
A: 可以，推荐使用Linux服务器
