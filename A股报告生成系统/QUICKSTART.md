# 快速使用指南

## 一键运行（推荐）

### 步骤1：打开命令行
```bash
cd C:\Users\ge0rg\Desktop\A股报告生成系统
```

### 步骤2：安装依赖（首次运行）
```bash
pip install -r requirements.txt
```

### 步骤3：运行批量生成
```bash
python batch_generate.py
```

## 输出位置

```

```


## 常见问题

**Q: 程序中断了怎么办？**
A: 重新运行即可，会继续生成（已跳过已生成的股票）

**Q: 如何只生成部分股票？**
A: 编辑 data/remaining_stocks.txt 文件，修改股票代码列表

**Q: API限流怎么办？**
A: 程序会自动等待，无需手动干预

**Q: 文件名重复怎么办？**
A: 程序会自动覆盖同名文件
